Description

  • The WRITE ontology provides a semantic model for contemporary Chinese calligraphy and its intersections with visual, performing, graffiti, and decorative and applied arts. It describes artworks, their calligraphic and writing-like components, literary works, people in different roles, exhibitions, artwork series, and other contextual elements, supporting their structured representation and analysis within the WRITE knowledge graph.

  • The creation of this knowledge graph is a part of the WenDAng - WRITE Digital Archive project. To learn more about it, please visit the offical documentation website.

  • The WRITE ontology was developed in collaboration with the domain experts, all of whom are members of the WRITE project team. To learn more about the project, please visit the offical website.

IRI http://www.wikidata.org/entity/Q1400264
Description

Group of artists who create works together.
Scope Note

Group of artists from diverse disciplines (e.g., calligraphers, graffiti writers, dancers, etc.) collaborating to create collective artistic works of any kind.

Traditional Artwork c

IRI https://w3id.org/write/ontology#TraditionalArtwork
Description

Artwork that follows traditional calligraphic canons and / or is created before 1980. This artwork does not belong to any of the four WRITE collections, but it is somehow related to one or more artworks from these collections.

Visual Arts c

IRI http://www.wikidata.org/entity/Q4502142
Description

Work of art that is primarily visual.
Scope Note

Includes artworks from the WRITE collection specifically categorised under Visual Arts.
Sub Class Of WRITE collections c

WRITE collections c

IRI https://w3id.org/write/ontology#WriteCollections
Description

Superclass that encompasses artworks from four distinct types of art (Visual Arts, Performing Arts, Graffiti Art, and Decorative and Applied Arts). There are four WRITE collections, one for each art category.
Super Class Of
  • Graffiti c
  • Performing Arts c
  • Visual Arts c
  • Decorative and Applied Arts c
