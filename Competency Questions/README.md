*** WRITE Competency Questions and SPARQL Queries ***
This page documents the 27 competency questions (CQs) developed for the WRITE project and their corresponding SPARQL queries. They are organized into three groups and support the examination of what can be retrieved from the WRITE RDF knowledge graph using the WRITE Ontology (v2.0.0).

The queries use direct properties only (no inverse properties). Each query retrieves all matching records; to query a particular resource, add a VALUES clause for the relevant variable (?artwork, ?unit, or ?artist) inside WHERE.
